# Мой день — веб-приложение

Приложение для iPhone (открывается в Safari и ставится на экран «Домой»): календарь и напоминания,
помощник Claude с голосом, деньги, еда по фото, вода и активность.

Это собранная версия. Исходники и сборка — в проекте виджета «Мой день» (`src/web`, `python3 build_web.py`).
Ключей и личных данных здесь нет: их приложение получает от виджета кодом подключения и хранит только на телефоне.
