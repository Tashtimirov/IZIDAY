# Мой день

Виджеты для iPhone и Mac: неделя с сегодняшнего дня и ближайшие события, напоминания, быстрые заметки, голосовые команды,
учёт доходов и расходов в батах с автозаписью в Google Таблицу, калории еды по фото, вода и активность с Apple Watch. Оформление — в цветах Prime Thai Property.

## Состав

| Папка | Что внутри |
|---|---|
| `src/iphone/MyDay.js` | Скрипт для Scriptable на iPhone: виджеты всех размеров, меню, встроенный разбор речи, ассистент Claude (по API-ключу) |
| `src/iphone/profile-ru.js` | Настройки версии для других людей: рубли, русские магазины, без личных календарей и таблиц |
| `src/mac/` | Виджет Übersicht для Mac и установщик `install.command` |
| `src/sheet/Code.gs` | Apps Script для Google Таблицы: принимает деньги, еду, воду и активность, сам создаёт листы и листы-итоги |
| `build_core.py` | Вырезает из iPhone-скрипта общее ядро (разбор речи, деньги, отчёты) для Mac |
| `build.py` | Собирает `dist/` и подставляет секреты из `secrets.json` |
| `tests/` | Набор фраз для проверки встроенного разбора |

## Сборка

```
cp secrets.example.json secrets.json   # заполнить
python3 build.py
```

Получится `dist/MyDay.js` (вставить в Scriptable), `dist/MyDay-Mac.zip` (установка на Mac:
`unzip MyDay-Mac.zip && zsh MyDay-Mac/install.command`) и `dist/Code.gs` (вставить в Apps Script таблицы).

`dist/MyDay-RU.js` и `dist/MyDay-TH.js` — готовые версии для других iPhone (Россия, рубли; Таиланд, баты). В исходнике личные настройки лежат между
`ЛИЧНЫЕ НАСТРОЙКИ (начало)` и `(конец)`; сборка заменяет этот блок на `profile-ru.js` и проверяет, что в файле не осталось
личных ссылок и ключей. Кнопки ▦ и ✓ появляются, только если в настройках указаны `sheetUrl` и `trackerUrl`.

## Google Таблица для других

Шаблон «Мой день — таблица (шаблон для других)» на Google Диске: листы «Операции», «Еда», «Вода», «Активность»
и итоги («Итоги: еда / активность / вода / деньги» — по дням и по месяцам, формулы QUERY).
В шаблон один раз вставляется `dist/Code-RU.gs` (Расширения → Apps Script). Каждый новый человек делает
копию шаблона (вместе со скриптом), разворачивает веб-приложение (доступ «Все») и вставляет ссылку в виджет:
меню → ▦ Google Таблица → Подключить автозапись. Ключ виджет создаёт сам, таблица запоминает первый пришедший;
ссылку на таблицу таблица присылает в ответ, после этого в шапке появляется ▦.

## Общий доступ друзей к Claude (версия для Таиланда)

`dist/Proxy.gs` — отдельный проект Apps Script владельца: ключ Anthropic лежит в его свойствах (`ANTHROPIC_KEY`),
виджет друзей знает только пароль (`ai_proxy_token` из secrets.json) и ссылку `/exec` (`ai_proxy`), которые сборка
подставляет в `MyDay-TH.js`. Лимиты: 40 запросов в день с телефона, 300 на всех; модель и `max_tokens` задаёт скрипт.
Свой ключ в виджете важнее общего доступа. В версии для России вместо Claude работает ChatGPT (`ai: "openai"` в `profile-ru.js`): фото еды и ассистент идут через OpenAI по ключу самого пользователя (меню → 🧠 Ассистент ChatGPT, ключ с platform.openai.com). Общего доступа там нет.

## Личный трекер

Кнопка ✓ в шапке открывает Google Таблицу «Мой день — личный трекер» на строке сегодняшнего дня (`trackerUrl`, `trackerStart`).
Лист «Дни»: дата, день недели, галочки «Алкоголь», «Курение», «Секс» и заметка. Лист «Месяцы» считает дни с каждой отметкой.
В Календарь ничего не записывается.

## Еда, вода и Apple Watch (iPhone)

- **📷 в шапке виджета** открывает камеру. Claude определяет блюда, вес порций, калории и БЖУ; оценку можно уточнить
  («половина порции, без соуса») или поправить калории вручную. Нужен ключ ассистента (меню → 🧠 Ассистент Claude).
- **Вода**: меню → 💧 Вода или нажатие на воду в виджете. Цель и размер стакана — `CONFIG.health`.
- **Параметр виджета `здоровье`** (средний или маленький): съедено, БЖУ, вода с прогрессом, активные калории, шаги, минуты упражнений.
  В большом виджете внизу всегда есть строка «еда · вода · активность».
- Голосом с ключом Claude: «съел тарелку борща», «выпил два стакана воды», «сколько я сегодня съел?».

### Apple Watch: Быстрая команда «Мой день - здоровье»

Scriptable не может читать «Здоровье» сам (так устроен доступ в iOS), поэтому цифры передаёт Быстрая команда.
«Фитнес» хранит кольца в «Здоровье», так что цифры те же. Соберите один раз в приложении «Быстрые команды»:

1. «Найти образцы здоровья»: Тип — **Шаги**, фильтр «Дата начала — сегодня», **Группировать по — День**
   (группировка нужна, чтобы шаги iPhone и часов не сложились дважды).
2. «Получить сведения об образцах здоровья» → **Значение**. Переименуйте результат в «Шаги».
3. Повторите 1–2 для **Активная энергия** (→ «Активные») и **Время упражнений** (→ «Упражнения»).
4. По желанию: **Пульс в покое** — без группировки, сортировка «Дата начала, сначала новые», ограничение 1 → «Пульс».
5. «Словарь»: ключи `steps`, `active`, `exercise`, `hr` → значения из шагов 2–4 (можно и русские ключи: шаги, активные, упражнения, пульс).
6. Scriptable «Run Script» (Выполнить скрипт): скрипт **MyDay**, Parameter — Словарь, «Run In App» **выключено**. Разверните действие (стрелка ›) и выключите **«Показывать при запуске»**, иначе после каждого запуска сверху всплывает окно «Run Script» с кнопкой «Готово».
7. Назовите команду ровно **«Мой день - здоровье»** — её запускает пункт меню «⌚ Обновить данные с часов».

Автообновление: «Быстрые команды» → Автоматизация → Время суток (например 9:00, 13:00, 17:00, 21:00) → эта команда →
«Запускать сразу», «Уведомлять при запуске» — выключено. Можно добавить и триггер «Приложение → Фитнес → Закрыто». Данные обновляются при запуске команды,
не в реальном времени. Принимаются ещё `stand` (часы с разминкой), `sleep` (сон, ч) и `distance` (км).

## Расходы по карте (Bangkok Bank и Kasikornbank)

Оплаты и переводы со счетов Bangkok Bank и Kasikornbank (письма K PLUS) записываются в расходы сами, наличные — как раньше, вручную.
Скрипт таблицы каждые 15 минут читает письма `bangkokbank.com` и `kasikornbank.com` о платежах и складывает их на лист «Карта»;
виджет при выгрузке забирает новые платежи и записывает их расходом «Перевод» (категория — по названию получателя),
после чего они попадают в «Операции». Если такая же сумма уже записана вручную (в пределах суток), виджет не добавляет
платёж, а спрашивает: уведомление «Похоже на дубль» → «Это одно и то же» / «Разные — добавить» / «Решить позже».
Пополнение своего K Plus Wallet считается расходом (о покупках из кошелька письма не приходят). Переводы на свои счета, в том числе Bangkok Bank ⇄ Kasikornbank (имя получателя содержит слово
из `card_skip` в secrets.json), — не расход, так траты не задваиваются. Письмо K PLUS, в котором не нашлась сумма, остаётся
на листе «Карта» со статусом «не разобрано» и в расходы не идёт.

Включение (один раз): вставить новый `dist/Code.gs` в Apps Script таблицы → «Развертывания» → «Управление» → ✏️ →
«Новая версия» → «Развернуть»; затем в таблице меню «Мой день» → «Расходы по карте: включить» и разрешить доступ к Gmail.
Берутся письма с момента включения. Проверить и решить дубли на iPhone: меню → 💳 Расходы по карте.

## Тесты разбора речи

```
node tests/run_corpus.mjs
node tests/run_corpus.mjs src/iphone/MyDay.js ./corpus2.mjs
node tests/health_test.mjs      # еда, вода, данные часов, отрисовка
node tests/agent_test.mjs       # ассистент: один system на разговор, повтор без «мыслей»
python3 build.py && node tests/ru_test.mjs && node tests/th_test.mjs   # версии для других: рубли / баты, категории, без личных кнопок
node tests/sheet_test.mjs      # автозапись: свой ключ, еда/вода/активность, без лишних отправок
node tests/gs_test.mjs         # скрипт таблицы на поддельной таблице: листы, без дублей, удаление
node tests/proxy_test.mjs      # общий доступ к Claude: пароль, лимиты, свой ключ важнее
node tests/card_test.mjs       # расходы по карте: письма банка, без дублей, вопрос про похожие записи
```

Секреты (`secrets.json`) в репозиторий не попадают.

## Возврат на экран «Домой» после операции из виджета

Scriptable не умеет сворачиваться сам, поэтому после операции, начатой из виджета (кнопки шапки, вода, еда, меню),
скрипт запускает Быструю команду **«Мой день - домой»** с одним действием «Перейти на экран «Домой»».
Создайте её один раз и включите: меню → 🏠 Возврат к виджету. Без неё всё работает как раньше.
Окно операции открывается сразу: выгрузка в таблицу идёт уже после возврата (не успеет — её догонит виджет).
