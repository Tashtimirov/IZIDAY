# Английский интерфейс (i18n)

Код пишется по-русски, как раньше. Английский — перевод на лету: `src/web/i18n.js` переводит текст на экране
по словарю `src/web/i18n-en.js` (русская строка → английская, `{0}` — вставки). Язык выбирают в Настройках → «Язык»
(хранится на телефоне, `izi-lang`); без выбора: у кого уже есть данные — русский, у новых — по языку телефона.
Валюта выбирается отдельно (Настройки → «Валюта»).

Как добавить перевод новых строк:
1. `python3 build.py && python3 build_web.py --no-minify`
2. `OUT=/tmp/s.json node i18n/extract.mjs dist/web $(cd dist/web && ls *.js | grep -v -E "^(sw|i18n|i18n-en)\.js$")` — все русские строки
   (нужен `npm i acorn@8 acorn-walk@8`).
3. Новые строки — в `i18n/tr/extra.tsv` («русский<TAB>английский»), или проверьте `node tests/i18n_en_test.mjs` — он печатает
   непереведённое на основных экранах.
4. `node i18n/compile.mjs i18n src/web/i18n-en.js`

`tr/NNN.tsv` — переводы по номерам строк из `keys.json`. Строки-подсказки для Claude не переводятся: Изи получает правило
«отвечай по-английски» (EN_RULE в app.js).
